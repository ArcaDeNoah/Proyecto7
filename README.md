# Panel de Control de Anuncios de Venta de Coches

Esta aplicación web interactiva desarrollada con Streamlit y Plotly permite analizar el conjunto de datos de anuncios de venta de vehículos en EE. UU.

## Funcionalidades
- Visualización de la distribución del odómetro mediante un histograma interactivo.
- Evaluación de la relación entre el millaje (odómetro) y el precio de los vehículos mediante un gráfico de dispersión.
